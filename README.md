# MCIS sample website

Premium public-site concept for MasterCare International School, Asaba.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Direction

- Existing MCIS logo is preserved.
- Real MCIS campus / school imagery is used where a reliable public source is available.
- The public website is intentionally separate from the later admissions / school-management build.
- The site is responsive and includes reduced-motion support.
